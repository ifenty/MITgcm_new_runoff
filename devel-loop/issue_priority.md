# Issue selection

Choose by scientific consequence, dependencies and bounded acceptance. Prioritize
silent incorrect results, invalid inference/data corruption, incorrect uncertainty,
then crashes/blocking capabilities and performance/readability as the project
requires. Record why the selected issue is timely. Keep deferred reasoning in its
open entry. A blocked issue is not selectable until its stated blocker is resolved
and Arch explicitly updates the status.

Any cost or scale figure an issue's scoping or deferral depends on (timesteps,
runtime, file size, call count) names its source: the file and line, command, or
receipt it was read from, for this issue's own experiment or target. A figure taken
from a neighbouring experiment's record is not a source. Deferring an issue on cost
grounds requires a measured cheap prefix of the real command (reduced steps, one
tile, one scenario), recorded in the open entry; an estimate is not enough.
